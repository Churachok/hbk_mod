# Исходные текстуры персонажей

`originals/` содержит архивные PNG-копии всех 11 JPEG из
`/home/kirill/Downloads/Telegram Desktop/lol/`. Их пиксели совпадают с
пикселями JPEG после декодирования. PNG нужен для ресурсов Minecraft.

Активные текстуры находятся в `src/main/resources/assets/hbk/textures/entity/`.
Сейчас они заменены готовыми PNG из `~/Downloads/Telegram Desktop/lol2/`;
прозрачность новых файлов уже правильная, дополнительная обработка не нужна.
Описанный ниже скрипт предназначен только для старых JPEG-исходников:
повторный запуск перезапишет новые скины прежними вариантами.

Ранее для JPEG применялась следующая обработка.
У JPEG нет прозрачности, поэтому белый фон внешнего слоя головы раньше
закрывал лицо. Скрипт оставляет все исходные цвета и UV-координаты, меняя
только прозрачность пустых пикселей во внешнем слое головы. Это позволяет
показать волосы и шапочку на модели; остальные внешние слои остаются скрытыми.

Чтобы повторить подготовку старых скинов, запустите
`bash scripts/clean_entity_textures.sh` из корня проекта.

Нужны Python 3 и ImageMagick.

`palettes/` — результат прежней обработки; при восстановлении не используется.
