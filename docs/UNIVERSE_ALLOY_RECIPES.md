# Изготовление сплавов

Все 45 пар симметричны. По одной руде **или** минералу каждого семейства дают один образец. Только плавильная печь: 200 тиков и топливо → один слиток. Каждый предмет требует один шаблон незеритового улучшения, указанную незеритовую основу и один слиток. Имя и зачарования основы сохраняются. Блок хранения = 9 слитков, разбирается обратно без потерь.
